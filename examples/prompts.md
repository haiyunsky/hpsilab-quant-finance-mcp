# HPSILab MCP Prompt Examples

Use these prompts in Claude, Cursor, ChatGPT Agents, Cline, Windsurf, or any MCP-compatible client after connecting the HPSILab MCP server.

## Full Workflow

```text
Analyze NVDA using HPSILab. Give me the bull/bear signal, confidence score, main bullish factors, main bearish factors, and a short risk note.
```

```text
Create a structured research report for SPY using HPSILab, including AI prediction, IV radar, option pressure, Monte Carlo outlook, equity curve context, and pre-trade risk.
```

## Options And Volatility

```text
Use HPSILab to check AAPL implied volatility. Summarize ATM IV, IV rank, IV percentile, volatility regime, and whether options look cheap or expensive.
```

```text
Use HPSILab option pressure for TSLA. Identify max pain, gamma wall, expected move, squeeze target, and any important strike-level pressure zones.
```

## Probability And Risk

```text
Run a HPSILab Monte Carlo simulation for QQQ. Report the 68% and 90% ranges, probability of finishing above spot, and probability of a 10% drawdown.
```

```text
Use HPSILab pre-trade risk scan for MSFT. Return the risk level, failed checks, warnings, and anything that should change position sizing.
```

## AI Prediction And Backtesting

```text
Use HPSILab AI prediction for META. Summarize the up probability, prediction, confidence, model votes, market regime, and signal strength.
```

```text
Use HPSILab equity curves for AMD. Compare the available strategy backtests by total return, Sharpe ratio, max drawdown, and win rate.
```

## Visuals

```text
Generate HPSILab stock images for NVDA and explain what each chart URL represents.
```
